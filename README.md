# Netflared Server — Forge

Server-side Forge port of Netflared Server.

The 1.21.x branch accepts a concrete minecraft_version and forge_version so CI can build each supported Forge release independently. Java 17 is used through 1.20.4 and Java 21 for 1.20.5/1.20.6.

Commands: /netflared, status, info, setup, connect, disconnect, reload, reset.
